# Bidra / Contributing

Svenska först, sedan engelska. Swedish first, then English.

## Svenska (SWE)

Bidrag är välkomna: rättningar, förbättringar och nya tester.

### Så bidrar du

- Öppna först ett ärende för allt som är större än en liten rättning, och beskriv problemet.
- Forka, skapa en gren från `main` och håll ändringen till en sak.
- Kör `npm run typecheck`, `npm run lint`, `npm test` och `npm run build` innan du öppnar pull requesten.
- Lägg till eller uppdatera tester (`tests/*.test.ts`) för det du ändrar.

### Texter i appen

- Användargränssnittet är på svenska. Håll nya texter korta och i samma ton som de befintliga.
- Använd samma namn som i [ordlistan](GLOSSARY.md), både på svenska och på engelska.

### Avtal om bidragslicens (CLA)

- Skriv under avtalet om bidragslicens en gång, i pull requesten. CLA-boten frågar dig.
- Avtalet finns på svenska ([CLA.sv.md](CLA.sv.md)) och engelska ([CLA.md](CLA.md)). Den svenska versionen gäller om de
  skiljer sig åt.
- Avtalet låter HINTEK Power Solutions AB ta med ditt bidrag i AGPL-3.0-utgåvan och i sin kommersiella utgåva. Du
  behåller upphovsrätten.

### Sårbarheter

- Rapportera inte sårbarheter i öppna ärenden. Följ [SECURITY.md](SECURITY.md).

## English (ENG)

Contributions are welcome: fixes, improvements and new tests.

### How to contribute

- For anything larger than a small fix, open an issue first and describe the problem.
- Fork, branch from `main` and keep the change to one thing.
- Run `npm run typecheck`, `npm run lint`, `npm test` and `npm run build` before you open the pull request.
- Add or update tests (`tests/*.test.ts`) for what you change.

### Texts in the app

- The user interface is in Swedish. Keep new texts short and in the tone of the existing ones.
- Use the names in the [glossary](GLOSSARY.md), in Swedish and in English alike.

### Contributor License Agreement (CLA)

- Sign the Contributor License Agreement once, in the pull request. The CLA bot asks you.
- The agreement is in Swedish ([CLA.sv.md](CLA.sv.md)) and English ([CLA.md](CLA.md)). The Swedish version governs if
  they differ.
- It lets HINTEK Power Solutions AB include your contribution in the AGPL-3.0 edition and in its commercial edition. You
  keep the copyright.

### Vulnerabilities

- Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
