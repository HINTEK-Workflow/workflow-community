# Säkerhetspolicy / Security policy

Svenska först, sedan engelska. Swedish first, then English.

## Svenska (SWE)

- Rapportera inte sårbarheter i öppna ärenden eller pull requests.
- Använd GitHubs privata sårbarhetsrapportering: fliken **Security** → **Report a vulnerability**. Rapporten syns
  bara för dig och för dem som underhåller arkivet.
- Beskriv problemet, hur det kan återskapas och vilken påverkan du ser.
- Bara det senaste släppet får säkerhetsrättningar.

## English (ENG)

- Do not report vulnerabilities in public issues or pull requests.
- Use GitHub's private vulnerability reporting: the **Security** tab → **Report a vulnerability**. Only you and the
  maintainers of the repository can see the report.
- Describe the problem, how to reproduce it and the impact you see.
- Only the latest release receives security fixes.
