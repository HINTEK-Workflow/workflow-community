# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting instead: the **Security** tab of this repository → **Report a
vulnerability**. Describe the problem, how to reproduce it and the impact you see.

We aim to acknowledge a report within five working days and to keep you informed until it is resolved.

## Supported versions

Only the latest release receives security fixes.
